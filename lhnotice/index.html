주요 기능

공고 확인부터 알림까지
임대픽 하나로

1분 자격진단 · 맞춤 공고

  • 나이, 혼인 여부, 가구원 수, 소득·자산 몇 가지만 답하면 끝
  • '신청 가능' / '확인 필요'로 한눈에 구분
  • 답변은 기기에만 저장되고 서버로 보내지 않아요

전국 LH 공고 한눈에

  • 지역·유형별 필터, 여러 지역 동시 선택
  • 공고명·지역·단지명으로 바로 검색
  • 최신순 / 마감임박순 정렬, 접수중·마감 구분
  • 매일 오전 7시~오후 10시, 1시간마다 새 공고 확인

공고 핵심만 쏙

  • 모집 세대수, 전용면적, 평수
  • 접수 기간, 당첨자 발표, 계약 일정
  • 주택형별 공급 세대·분양가(임대보증금)
  • 마감까지 D-day 표시, 공고문 바로 열기

새 공고 알림

  • 관심 지역과 공고 유형을 고르면 새 공고를 바로 알려드려요
  • 마음에 드는 공고는 별표로 저장

평수계산기

  • "26.37㎡가 몇 평이지?" 바로 계산
  • 공고 카드와 상세 화면에도 평수 표시

오늘의 운세

  • 청약 넣기 전, 12띠 오늘의 운세로 가볍게 하루 시작
  • 재미로 보는 콘텐츠예요
행복주택국민임대영구임대 매입임대전세임대든든전세 통합공공임대공공분양신혼희망타운

임대픽은 LH(한국토지주택공사)의 공식 앱이 아닙니다. 정확한 신청 자격과 일정은 LH청약플러스 원본 공고문에서 확인해 주세요.

본 앱은 공공데이터포털(data.go.kr)의 한국토지주택공사 공개 API 정보를 활용합니다. 자격진단 결과는 참고용이며, 실제 자격과 당첨 여부는 원본 공고문 기준입니다.
